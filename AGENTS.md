# Repository Instructions

## Change execution

For changes spanning multiple files, renames, or combined create/delete operations, work against the repository as a coherent workspace rather than through per-file remote mutation APIs.

Avoid creating incidental commits as a side effect of file editing. Keep a coherent logical change together so it can be reviewed and committed as one commit when appropriate.

## Scope

Preserve unrelated user changes. Follow the repository's existing validation and workflow instructions when they apply.
